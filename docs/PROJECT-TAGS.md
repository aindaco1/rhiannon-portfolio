# Project tags

Editorial pass: November 17, 2026. All 20 projects use a shared vocabulary of 18 tags.

Categories retain the broad disciplines. Tags describe medium, format, technique, or production documentation, with one to four useful tags per project. Labels use sentence case, stable lowercase hyphenated slugs, and alphabetical order. Generic sample labels Character study, Texture, Color, and Objects were unused and removed. Music Video is now Music video, keeping its existing URL.

Assignments are editorial best guesses from the supplied images, clips, project names, and Bio/resume. They are browsing aids rather than new role credits or genre claims. The Short film assignment for First Time Sexpot is provisional because the supplied material is production photographs rather than a complete film.
